ZFUN is a focused interface for creating meme tokens through the existing Flap V7 Portal on BNB Chain, with ZEC fixed as both the trading pair and holder-dividend asset.

Overview

ZFUN is a normal token launcher—not a signal feed or trend dashboard. Creators provide a token name, symbol, description, artwork and optional social links. The interface prepares a Flap V7 launch and asks the connected wallet to sign the final transaction.

ZFUN does not deploy a separate launcher contract. It uses the existing Flap V7 Portal.

Fixed launch configuration

  • Network: BNB Smart Chain, chain ID 56.
  • Quote / paired asset: ZEC.
  • Holder-dividend asset: ZEC.
  • Holder fee allocation: 10,000 bps, or 100% of the configured holder-fee allocation.
  • Buy and sell tax rate: 0 in the launch parameters.
  • Native value: 0 BNB; BNB is required only for network gas.

There is no quote-token selector and no dividend-basket selector in the interface.

Launch flow

  1. Connect an EIP-1193 wallet and switch to BNB Smart Chain.
  2. Enter the token details and upload artwork.
  3. ZFUN checks that Flap currently enables ZEC as a quote token.
  4. Metadata is uploaded through Flap's metadata service.
  5. The browser derives an unused token address ending in 8888.
  6. The wallet reviews and signs the Flap V7 transaction.
  7. After confirmation, ZFUN verifies and adds the launch to its public registry.

No transaction is sent until the user explicitly confirms it in the wallet.

Public launch registry

The Leaderboard page does not contain mock tokens. A listing is accepted only when the backend verifies the transaction receipt, confirms that the transaction targeted the Flap V7 Portal, checks the creator address, confirms deployed bytecode, and reads the token name and symbol from the deployed contract.

Connecting a wallet on the launcher filters “Your launches” by creator address. Public launches remain visible to everyone on the Leaderboard.

ZEC market chart

The Dividends page displays live ZEC/USDT candles from Binance's credential-free public market API. The chart offers 15-minute, 1-hour, 4-hour and daily intervals. Market prices are informational and are not presented as dividend balances or reward estimates.

Wallet and transaction safety

  • ZFUN never requests or stores a private key or seed phrase.
  • Wallet connection is initiated only by a user click.
  • The chain and active account are checked again before launch.
  • The final calldata, gas estimate and transaction are reviewed by the wallet.
  • Always verify the destination, network and values before signing.
